# AJATT Grammar Guide

AJATT Grammar Guide is a Japanese grammar guide for beginners and new learners.

View the project at [grammar.ajatt.top](https://grammar.ajatt.top).

Contribute by joining our [community](https://ajatt.top/blog/join-our-community.html).

Note:
The guide is based on [yokubi](https://github.com/Morgawr/yokubi),
which itself is based on [Sakubi](https://sakubi.neocities.org/).
Most grammar guides,
including the original yokubi/sakubi and many popular ones like Tae Kim,
go against AJATT in many places.
This guide has been improved and adapted to support the
[AJATT philosophy](https://ajatt.top/blog/whats-ajatt.html) rather than contradict it,
making it a good choice for newcommers to AJATT.
