# Other resources

It's true that everyone learns the same way when it comes to mastery, fluency,
exposure, and real-world experience, but not everyone learns the same way when
it comes to deliberate study.

This guide is about deliberate study, and it might not be right for everyone.
If this guide doesn't help you after two weeks, try other resources.

See [the main AJATT site](https://ajatt.top/blog/learning-grammar.html#grammar-guides)
for recommended grammar guides.

Don't burn yourself out trying to master them.
Mastery only comes from real-world experience,
and in language learning
that means immersion (reading and listening).
